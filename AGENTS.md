# Repository instructions

Product specifications and design start at [docs/PROJECT.md](docs/PROJECT.md).
Individual domain specifications are in [docs/specs/](docs/specs/).

Before planning or implementing work, read the specifications relevant to the
task. Do not infer or change specifications to fit existing implementation.
If an important prerequisite is not met, report the investigation result.

`docs/research/` contains reference material; it is not the Source of Truth
for product specifications.
