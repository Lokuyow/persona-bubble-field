# persona-bubble-field

Bootstrap repository for a SvelteKit static web application. The public
service name and product UI are not decided yet; this repository name is only
a temporary development identifier.

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run check
npm run build
```

For a GitHub Pages project site, set `BASE_PATH` to the repository path when
building, for example `BASE_PATH=/persona-bubble-field npm run build`. The
deployment workflow derives this value from the repository name automatically.
